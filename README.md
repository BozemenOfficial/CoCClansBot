# CoCClansBot

Первая версия — привязка Clash of Clans к Telegram, игровой профиль и синхронизация ника в теге группы. Личный кабинет работает в Telegram Mini App; группа управляется командами администратора.

Бот: [@CoCClansBot](https://t.me/CoCClansBot). Приложение: [coc-clans-bot.loopnexo.workers.dev/app/](https://coc-clans-bot.loopnexo.workers.dev/app/). Открывать приложение для входа нужно кнопкой в боте: обычный браузер не получает Telegram-авторизацию.

## Что входит в первую версию

- Профиль с игровым ником, Player Tag, кланом, ратушей, кубками и уровнем.
- Однократная привязка свободного тега из состава подключённого клана. Пользователь должен состоять и в соответствующей Telegram-группе.
- Сразу после привязки бот пробует поставить игровой ник в тег участника группы.
- Автопроверка раз в час. Совпадающий тег не перезаписывается.
- Выключатель синхронизации: аккаунт пропускается и при автоматической, и при принудительной проверке.
- Подтверждаемая отвязка и последующая привязка другого аккаунта.
- `/setup #ТЕГ_КЛАНА`, `/status`, `/sync` только для администраторов группы.

Игровой API Token от участника не нужен. Любой свободный тег из состава принимается автоматически: владение аккаунтом эта схема не подтверждает. Один тег нельзя связать с двумя Telegram-пользователями.

Модерации, ограничений сообщений, удалений участников, войн и уведомлений в первой версии нет. Исторические таблицы модерации сохраняются в D1, но её обработчики удалены, а включённые флаги сбрасываются миграцией.

## Подключить группу

1. Добавить бота в супергруппу и выдать право управлять тегами участников (`can_manage_tags`). Право ограничивать участников не требуется.
2. Администратору от своего имени отправить `/setup #ТЕГ_КЛАНА`.
3. Участнику вступить в игровой клан и Telegram-группу, открыть личный чат бота, нажать «Открыть» и указать Player Tag.
4. Посмотреть результат в разделе «Синхронизация». Telegram не позволяет боту ставить такой тег администратору или владельцу группы: они пропускаются.

Существующие привязки сохраняются: проходить регистрацию повторно не нужно. При повторном вступлении бот обновляет запись членства; событие не запускает принудительную синхронизацию.

## Принудительное обновление

Только действующий администратор может вызвать `/sync` в группе. Команда проходит **всех привязанных участников этой группы с включённой синхронизацией**. Другие группы не затрагиваются. Бот проверяет актуальное членство и права перед записью, а тег меняет только при отличии от игрового ника.

Большой список обрабатывается партиями с сохранением курсора в D1. Первая партия выполняется сразу, остальные — очередью; результат публикуется после завершения. Повторная команда не сбрасывает активную задачу. Неудачная отправка итогового сообщения повторяется отдельно от изменения тегов.

В Mini App нет метода принудительного изменения тега. Кнопка обновления профиля только читает свежие игровые данные. Включение переключателя сохраняет настройку, а тег изменится при следующей плановой проверке или команде администратора.

При выключении синхронизации текущий тег остаётся. При отвязке бот пытается удалить только свой неизменённый тег; ручные правки сохраняются. Ошибка очистки показывается отдельно. Отвязка освобождает Player Tag, но не сбрасывает часовой таймер.

## Архитектура и запуск

Исходники и схема модулей — в [описании архитектуры](docs/architecture.md). Для VS Code откройте `CoCClansBot.code-workspace`.

Нужны Node.js 24 и pnpm 11.25.0:

```bash
pnpm install --frozen-lockfile
cp .env.example .dev.vars
pnpm db:local
pnpm check
pnpm dev
```

Mini App раздаётся тем же Cloudflare Worker из `public/app/`, без отдельного хостинга и сборки. Для настоящего входа его нужно открыть из Telegram по публичному HTTPS-адресу. Локальная база находится в `.wrangler/`; `db:local` не меняет рабочую D1.

Для развёртывания в другом аккаунте создайте D1, замените её ID и `MINI_APP_URL` в `wrangler.toml`. Добавьте секреты:

```bash
pnpm exec wrangler secret put BOT_TOKEN
pnpm exec wrangler secret put WEBHOOK_SECRET
pnpm exec wrangler secret put COC_API_TOKEN
pnpm db:remote
pnpm deploy
```

Сейчас используется RoyaleAPI: `COC_TRANSPORT=royaleapi`, `COC_API_BASE_URL=https://cocproxy.royaleapi.dev/v1`. Ключ разработчика Clash API должен разрешать IP этого прокси. [Варианты подключения](docs/connection-options.md) и [свой gateway](docs/gateway.md) описаны отдельно. Секрет разработчика хранится только на сервере.

Добавьте в `.dev.vars` `BOT_TOKEN`, `WEBHOOK_SECRET` и `WEBHOOK_URL=https://ВАШ-WORKER.workers.dev/webhook`, затем:

```bash
pnpm webhook
# Для окружения с HTTP_PROXY/HTTPS_PROXY:
# NODE_USE_ENV_PROXY=1 pnpm webhook
```

Скрипт установит кнопку Mini App в меню бота, разделит личные и групповые команды и включит доставку `chat_member`. Ожидающие обновления не удаляются. Для другой установки проверьте, что `MINI_APP_URL` и адрес кнопки ведут на один Worker.

## Авторизация и ограничения

Сервер проверяет HMAC подпись Telegram `initData`, время выдачи (не старше часа) и идентификатор пользователя. Из `initDataUnsafe`, URL и JSON тела пользователь не выбирается. Просроченный сеанс требует повторного открытия приложения. Секреты и launch data не записываются в браузерное хранилище; ответы личного API имеют `Cache-Control: no-store`.

Изменения привязки и настроек используют те же блокировки, что webhook и синхронизация. Запись тега идемпотентна, а уникальные индексы защищают привязки от гонок. API ограничивает размер тела и частоту запросов.

Планировщик просыпается каждую минуту, чтобы продолжать очереди, но успешно проверенный аккаунт снова становится доступен для автопроверки только через 3600 секунд. За запуск обрабатывается до 3 игроков, не более 40 внешних запросов с таймаутами. При большом количестве аккаунтов или групп обновление может задерживаться; гарантии одновременной проверки всех ровно на границе часа нет. При выходе игрока из подключённого клана бот пропускает изменение тега, не меняя права человека.

Тесты выполняют настоящие SQL-миграции в SQLite, проверяют подписанную авторизацию Mini App, привязку, отключение синхронизации, отвязку, права администратора, очереди больших списков, webhook и сетевые сбои. Внешние API подставляются; проверки ограничений реальных участников не выполняются.

Мобильный интерфейс можно проверить отдельно при запущенном `pnpm dev`: `python3 scripts/test-miniapp.py` (нужны Python Playwright и Chromium в `/usr/bin/chromium`). Скрипт подставляет ответы API, проверяет навигацию, отключение синхронизации, подтверждение отвязки и повторную привязку; реальные аккаунты не изменяет. Снимки сохраняются в `/tmp/coc-miniapp-browser`.

## Изоляция групп и административный сброс

Новые группы активирует только `BOT_OWNER_ID` из серверных настроек. Если ID не задан, активация закрыта. Существующие подключения сохраняются. Владелец также должен быть администратором активируемой группы. Дальнейшая настройка своей группы доступна её администраторам; одинаковый `/setup` идемпотентен, смена клана отменяет только очередь этой группы.

`/resetlink TELEGRAM_ID причина` сбрасывает спорную привязку участника, которая относится исключительно к текущей группе. Проверяются живое членство и права администратора, причина сохраняется в `admin_audit`. Общую для нескольких групп привязку команда не сбрасывает: такой спор требует владельца и ручной проверки, чтобы администратор одной группы не управлял другими.

Групповые связи восстанавливаются из соответствия клану и уточняются через Telegram перед записью. Ручные и автоматические очереди получают разные минутные такты; группы выбираются по времени последнего запуска. Неудачные задачи откладываются с учётом `retry_after`, после пяти ошибок прекращаются. Неудачная отправка результата повторяется ограниченно и не блокирует другие группы. Автопроверка при большой нагрузке может задерживаться.

Игровой кеш хранит до 500 ответов; личный кабинет использует TTL 60 секунд, синхронизация читает API заново. Частота запросов ограничивается по игровому пути. При недоступности API отображаются сохранённые данные с отметкой времени. Транспорт RoyaleAPI сохранён.

Порядок замены ключей — в [инструкции ротации](docs/secret-rotation.md).
