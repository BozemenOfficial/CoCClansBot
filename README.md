# CoCClansBot

Telegram-бот для кланов Clash of Clans. Игрок подтверждает свой аккаунт через API Token из игры, а бот ставит его игровой ник в тег участника Telegram-группы.

## Что работает

- Привязка аккаунта в личном чате: тег игрока → найденный профиль → проверка владения через `verifytoken`.
- Один игровой аккаунт нельзя привязать к двум Telegram-пользователям. Самостоятельная перепривязка пока отключена.
- Профиль с ником, кланом, ратушей, уровнем, кубками, пожертвованиями и ролью.
- Inline-меню: профиль, привязка, обновление данных и настройки.
- `/setup #ТЕГ_КЛАНА`, `/status` и `/sync` для администраторов группы.
- Обновление тегов через `setChatMemberTag`: без эмодзи, не длиннее 16 символов. Администраторы, отсутствующие участники и группы без нужных прав пропускаются.
- Плановая синхронизация через Cron. Повторная доставка webhook и одновременные проверки защищены записями в D1.

У каждой группы свой клан и состояние синхронизации. Тег обновляется для подтверждённого игрока, который состоит в подключённой группе. Если он вышел из игрового клана, бот продолжает обновлять ник и **не удаляет его из Telegram**.

Войны, аналитика, платежи и веб-панель в эту версию не входят.

## Устройство проекта

```text
src/
  index.ts             HTTP webhook и Cron handler
  config.ts            проверка настроек через Zod
  webhook.ts           секрет webhook и разбор запроса
  bot/
    create.ts          grammY и общие ограничения
    admin.ts           команды администратора
    player.ts          личный чат и inline-кнопки
    menu.ts            меню и текст профиля
  clients/
    clash.ts           официальный API или собственный gateway
    http.ts            таймауты и бюджет внешних запросов
  db/store.ts          запросы D1, блокировки и ограничения частоты
  services/
    linking.ts         проверка владения аккаунтом
    sync.ts            проверка участников и обновление тегов
  validation/player.ts теги игрока и очистка ника
gateway/server.ts      отдельный сервер для доступа с постоянного IP
migrations/            схема D1 и курсоры синхронизации
scripts/webhook.mjs    регистрация команд и webhook
tests/                 SQLite, подставные API и сценарии grammY
docs/gateway.md        настройка доступа к Clash API
```

Worker принимает обновление только с правильным секретом Telegram. Привязки, настройки групп, текущие имена и состояние задач хранятся в D1. Истории игровой статистики нет. Cron использует тот же сервис синхронизации, что и ручная проверка.

## Локальный запуск

Нужны Node.js 24 и pnpm 11.25.0.

```bash
pnpm install --frozen-lockfile
cp .env.example .dev.vars
pnpm db:local
pnpm check
pnpm dev
```

Заполните `.dev.vars` своими значениями. Локальная база создаётся в `.wrangler/`; реальную D1 эти команды не меняют. Без секретов `/health` всё равно отвечает, но бот не обрабатывает обновления.

```bash
curl http://localhost:8787/health
# Ручной вызов Cron локально; нужны заполненные настройки:
curl 'http://localhost:8787/cdn-cgi/handler/scheduled?cron=*/30+*+*+*+*'
```

Telegram не может отправлять webhook на localhost. Для ручной проверки в Telegram нужен доступный HTTPS-адрес Worker или доверенный HTTPS-туннель. Не перенаправляйте рабочий бот на тестовую среду: используйте отдельного бота для разработки.

Тесты не требуют настоящих токенов: они выполняют миграции и запросы в SQLite, а ответы внешних API подставляют. В тестах проверяются привязка и отказ в захвате чужого аккаунта, лимиты попыток, команды через grammY, права администратора, синхронизация, повторные webhook, таймауты и работа gateway.

## Подключение Cloudflare

1. Войдите в аккаунт и создайте базу:

   ```bash
   pnpm exec wrangler login
   pnpm exec wrangler d1 create coc-clans-bot
   ```

2. Замените нулевой `database_id` в `wrangler.toml` ID созданной базы. Это заглушка для локальной разработки, а не готовая удалённая база.
3. Выберите транспорт Clash API. Для обычного Worker сначала прочитайте [инструкцию gateway](docs/gateway.md): прямой доступ часто блокируется из-за IP allowlist.
4. Сохраните секреты интерактивно:

   ```bash
   pnpm exec wrangler secret put BOT_TOKEN
   pnpm exec wrangler secret put WEBHOOK_SECRET
   # Только для direct:
   pnpm exec wrangler secret put COC_API_TOKEN
   # Либо для gateway:
   pnpm exec wrangler secret put COC_GATEWAY_TOKEN
   ```

   `WEBHOOK_SECRET` — случайная строка длиной от 32 символов, например результат `openssl rand -hex 32`. Telegram допускает латинские буквы, цифры, `_` и `-`. Сохраните то же значение в локальном `.dev.vars` для регистрации webhook.

5. Примените миграции и разверните Worker:

   ```bash
   pnpm db:remote
   pnpm deploy
   ```

   Cron `*/30 * * * *` уже указан в конфигурации. Проверьте его появление в панели Cloudflare; изменение расписания может применяться не сразу.

## Подключение Telegram

1. Добавьте в локальный `.dev.vars` переменную `WEBHOOK_URL` с адресом `https://ВАШ-WORKER.workers.dev/webhook`. Там же должны быть настоящий `BOT_TOKEN` и тот же `WEBHOOK_SECRET`, что в Worker.
2. Выполните:

   ```bash
   pnpm webhook
   ```

   Скрипт зарегистрирует команды, задаст webhook с секретом и проверит сохранённый URL. Существующие ожидающие обновления не удаляются. В консоль не выводятся токены и полные ошибки Telegram.

3. Добавьте бота в группу. Назначьте его администратором и включите право управлять тегами участников (`can_manage_tags`).
4. От своего имени отправьте в группе `/setup #ТЕГ_КЛАНА`. Команда от анонимного администратора не принимается.
5. В личном чате бота отправьте `/start` и привяжите игрока. Нужен именно API Token из дополнительных настроек Clash of Clans. Код входа и пароль Supercell ID бот не запрашивает.
6. Проверьте `/status`, затем `/sync`. У обычного участника должен появиться игровой ник в теге. Для администраторов Telegram этот метод не применяется.

## Лимиты и поведение при сбоях

По умолчанию Cron каждые 30 минут берёт до **8 просроченных игроков**, а не весь список без ограничения. `SYNC_BATCH_SIZE` можно менять от 1 до 20. В одном запуске допускается не больше 40 внешних запросов; для каждого стоит таймаут 5 секунд. При большом числе групп бот сохраняет позицию и продолжает с неё позже. Поэтому для большого списка интервал обновления **будет больше 30 минут**. Перед расширением нагрузки нужно измерить расход CPU, запросов и D1 на вашем тарифе; [лимиты Workers](https://developers.cloudflare.com/workers/platform/limits/) могут меняться.

`/sync` обрабатывает следующую партию только в текущей группе. Команда доступна раз в минуту. При частичной обработке повторите её, чтобы пройти дальше; Cron продолжает свою проверку независимо от ручного курсора. После полного прохода следующий вызов начинает проверку заново.

Ник читается один раз на игрока в рамках запуска. Перед изменением бот смотрит живой тег в Telegram: совпадающий тег не перезаписывается, ручные изменения исправляются. Ошибки `429` переносят повторную попытку; бесконечных повторов и ожидания внутри Worker нет.

Запись `webhook_updates` хранит результат обработки семь дней. Активная обработка защищена арендой на две минуты; блокировки освобождаются только владельцем. Разные сообщения одного пользователя обрабатываются последовательно. Это защищает запись привязки, но не даёт абсолютной гарантии однократной отправки сообщений: при сбое между отправкой в Telegram и записью результата ответ может повториться. Установка тега идемпотентна.

API Token игрока не записывается в D1. Сообщение с ним бот пытается удалить до обращения к API, но Telegram может отказать в удалении. Проверка идёт в памяти процесса. Логи приложения содержат только код ошибки или счётчики; не включайте подробное логирование HTTP-тел и webhook в сторонних инструментах.

## Что нужно для настоящего запуска

- Токен уже созданного бота из BotFather.
- Аккаунт Cloudflare, доступ Wrangler и ID базы D1.
- Случайный секрет webhook.
- Ключ Clash API с разрешённым исходящим IP.
- Для обычных Workers — свой доступный HTTPS gateway со стабильным IP и отдельным секретом.
- Права бота на управление тегами в каждой группе.

Платные сервисы автоматически не подключаются. Worker и D1 рассчитаны на небольшой бот в пределах бесплатных квот. Бесплатный надёжный gateway проект не обещает: если сервера с постоянным IP нет, это отдельное условие запуска.

Описание метода Telegram: [setChatMemberTag](https://core.telegram.org/bots/api#setchatmembertag). Документация Clash API: [портал Supercell](https://developer.clashofclans.com/).
